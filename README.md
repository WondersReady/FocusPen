# FocusPen · 焦点笔增强

面向小米平板 HyperOS 的 LSPosed 模块，在系统手写笔设置中整合按键配置、快捷环、笔尖预览、书写声音和使用指南。

## 功能

- 标准版焦点笔的速记键、截图键支持短按、长按和快速双击配置；“交给前台应用”用于应用自身的笔动作。
- 全局默认、应用配置与可复用模板，跟随当前焦点窗口选择配置。
- 最多 12 项的弧形菜单，支持官方速记、区域截屏、小爱识屏和应用；提供多选、排序及图标预览。
- 标准笔焦点键由模块统一识别短按、长按和快速双击；演示模式提供激光、圈注与换色，鼠标模式使用系统鼠标设备并支持左右键及拖动。
- 息屏速记独立开关，可选择笔记或小米创作；锁屏使用限定的官方动作。
- 系统设置沿用宿主原生组件。独立 MIUIX 管理器提供加载状态、配置导入导出、笔型预览、GitHub Release 更新检查和开源致谢；更新只提示下载，不自动安装。

## 支持范围

当前针对小米平板 8 Pro 的特定 HyperOS ROM 适配：

```text
Xiaomi/piano/piano:17/CP2A.260605.016/OS4.0.2.0.XPYCNXM:user/release-keys
```

标准版焦点笔用于开发验证；焦点笔 Pro 已有源码接入与界面预览，尚未完成实笔验证。激光、鼠标、锁屏、息屏及多窗口等路径仍有待完成的设备验收；其他 ROM 不视为已兼容。鼠标指南中的笔姿态打磨推迟到下一版。

## 安装与构建

安装发布页中的 APK，在 LSPosed 中启用模块。静态作用域为 `system`、`com.android.systemui`、`com.miui.securitycore`、`com.xiaomi.touchservice`。首次启用或更新系统输入代码需要重启；纯界面更新只需重新打开对应宿主界面。

1.0 Beta 起应用 ID 从 `com.focuspen.enhance.v2` 改为 `io.github.wondersready.focuspen`。Android 会将其视为另一款应用，不能把新包直接覆盖安装到旧包；旧包的私有配置也不会自动迁移。升级前在旧版管理器导出配置，在新版导入，并在 LSPosed 中停用旧包、启用新包，避免两套 Hook 同时运行。

功能设置入口：系统设置 → 手写笔与键盘 → 手写笔 → 功能设置。独立应用提供进入设置的入口。

构建环境、测试和配置备份见 [构建说明](docs/BUILD.md)。架构与行为边界见 [设计说明](docs/DESIGN.md)。1.0 Beta 的功能和未验收范围见 [1.0 Beta 说明](docs/releases/1.0-Beta.md)；旧版记录见 [0.7.7 发布说明](docs/releases/0.7.7.md)。
