# 尚未发布的开发改动

当前开发版本为 `0.7.7-editor-dev`（versionCode 32）。公开发行基线仍为 `v0.7.6`；以下改动不包含在 0.7.6 APK 中。

- 添加应用配置及菜单项目选择页统一使用 36 dp 图标区域，图标等比缩放；应用名称和包名单行省略，避免各条目因素材尺寸或文字换行而高度不一致。复用为普通条目时恢复原生样式。
- 拖动已选项目至列表边缘时自动滚动，速度随距离变化；手指停留在边缘时继续滚动，并接纳新出现的条目。仅在已选项目范围内滚动，候选项目不参与排序。
- 相邻条目仅在目标位置变化时启动让位动画。松手、取消、多指或离开页面后停止滚动，避免残留回调影响后续操作。

本地生产代码替身测试覆盖首尾互换、边缘滚动范围、新出现条目、静止时不重复启动动画、混合行高，以及取消、多指、分离和轻触。Gradle debug 构建通过。

这些改动尚未在平板上验收；真实列表回收、动效流畅度、深浅主题与分屏效果仍需设备检查。Pro 硬件未验证。
