# 尚未发布的开发改动

当前开发版本为 `0.7.7-editor-dev`（versionCode 32）。公开发行基线仍为 `v0.7.6`；以下改动不包含在 0.7.6 APK 中。

手写输入第三页的官方动画引用外部图片。动态创建的动画视图现已补齐官方布局使用的 `img/` 图片目录，避免图片层绘制时因目录未设置抛出异常。宿主替身回归在旧代码失败、修正后通过，构建通过；尚待实际崩溃日志和设备翻页复验，图片本身是否完整也需检查。

列表及圆环预览拖动在松手时重新计算最终位置，修正最后一次 MOVE 与 UP 坐标不同时提交到旧位置的问题。列表生产代码回归先复现“从第一项拖至第三项却提交到第二项”，修正后正反向、回到原位及取消均通过；圆环采用同样的最终坐标规则，邻项随最终落点让位。Gradle debug 构建通过；圆环的实际触摸及动效仍待设备验收。

- 添加应用配置及菜单项目选择页统一使用 36 dp 图标区域，图标等比缩放；应用名称和包名单行省略，避免各条目因素材尺寸或文字换行而高度不一致。复用为普通条目时恢复原生样式。
- 拖动已选项目至列表边缘时自动滚动，速度随距离变化；手指停留在边缘时继续滚动，并接纳新出现的条目。仅在已选项目范围内滚动，候选项目不参与排序。
- 相邻条目仅在目标位置变化时启动让位动画。松手、取消、多指或离开页面后停止滚动，避免残留回调影响后续操作。

本地生产代码替身测试覆盖首尾互换、边缘滚动范围、新出现条目、静止时不重复启动动画、混合行高，以及取消、多指、分离和轻触。Gradle debug 构建通过。

这些改动尚未在平板上验收；真实列表回收、动效流畅度、深浅主题与分屏效果仍需设备检查。Pro 硬件未验证。

输入检查另补充了生产 `PenKeyHost` 的换色路由与允许条件：两键方向、普通动作排除，以及游戏、相机、锁屏、息屏和配置／厂商状态不可用时的限制。本地检查通过；测试使用换色路由探针，真实颜色及按键配对逻辑由 `test_presentation.py` 覆盖。实机换色偶发隐藏仍未复现，尚不认定修复。

## 应用按键释放修正

“交给前台应用”已转发 DOWN 后，如果配置在松手前变化或变为不可用，旧实现会丢弃 UP。现已将结束已开始按键与开始新动作的条件分开：原窗口及焦点代次未变、屏幕可交互且未锁定时，补发带 `FLAG_CANCELED` 的 UP，保留笔设备、键码、扫描码、修饰键与来源；普通重复事件仍受原配置有效性限制。

回归测试先在旧实现复现失败，修正后通过。覆盖配置变化／不可用、DOWN 尚在队列、同应用换窗、离开后返回、锁屏、息屏及两键原始身份。Gradle debug 构建通过；尚未在第三方应用实测。本修正位于 0.7.7 开发分支，0.7.6 Release 保持原样。
