# FocusPen 0.7.6

本次发布保留已交付预览包，APK 内版本名为 `0.7.6-guide-dev`，versionCode 为 31，配置 schema 为 14。后续开发改动不纳入此 APK。

## 本版整理

- 原生设置中的全局按键、应用配置、模板、菜单编辑及统一使用指南。
- 教程各页采用一致的按钮几何；使用“短暂按住”“快速连按”的说明。
- 列表复用、开关更新、真实行拖动和圆环图标排序。
- 教程笔尖定位、倾角、笔迹出现与抬笔回程动画；打断动画时保留连续性。
- 教程共享解析后的官方素材，避免逐页重复解码。
- 原始按键向前台应用透传、锁屏／息屏笔记入口的源码修订。

## 验证状态

Gradle debug 构建及相关配置、输入、动效、教程生命周期本地检查已通过。标准笔此前完成了快捷环位置、朝向和避边，以及悬浮预览与落笔隐藏的实笔检查；该结果不覆盖所有后续修改。

仍待完成：新版排序与动画设备验收、系统宿主重载后的应用透传与锁屏／息屏速记完整流程、激光换色偶发退出的定位、Pro 实笔测试。

已知界面问题：添加应用配置时部分应用图标大小和条目高度不一致；已选长列表拖到屏外的自动滚动尚未包含在 0.7.6。相关修订在后续开发中。
