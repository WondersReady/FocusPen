# FocusPen 0.7.7

本次为开发预览版，APK 内版本名 `0.7.7-editor-dev`，versionCode 32，配置 schema 14。

## 更新

- 统一应用配置和菜单候选列表的图标区域、名称与包名行数，减少条目高度不一致。
- 菜单排序支持拖至列表边缘自动滚动；快速拖动按最终松手位置落位，圆环预览同步修正。
- 修正前台应用收到按键 DOWN 后，配置变化导致 UP 丢失的问题；同一窗口可收到带取消标记的释放事件。
- 手写输入教程补齐官方动画图片目录，修正第三页图片层可能因目录缺失而崩溃的加载路径。
- 标准版按键设置和教程补充鼠标操作说明：闲置时双击焦点键进入／退出，速记键为左键，截图键为右键，按住可拖动。

## 验证与已知问题

Gradle debug 构建通过；菜单拖动、应用事件目标、教程生命周期和演示 hook 的相关本地回归通过。测试使用生产代码配合宿主替身，不等于设备验收。

仍需实机确认：新版列表回收和动效、第三页崩溃是否消失及图片完整性、标准笔鼠标触发和拖动、前台应用透传、锁屏／息屏笔记完整路径。激光换色偶发隐藏仍待定位；Pro 无实笔验证。支持 ROM 限定见 README。

纯 UI 修正无需重启；本版同时包含系统输入修正，该部分需要系统宿主重新加载。若管理器提示宿主版本未更新，应在方便时重启后验证输入功能。
