# FocusPen 1.1

1.1 正式版继续完善输入与设置体验，并暂时停用尚未达到预期的书写声音反馈。

- 按键识别时间支持 100–400 ms 连续调节，在 200 ms、300 ms 附近吸附；拖动时实时显示数值，松手后保存，取消拖动不修改配置。
- 修复设置滑条触碰时可能导致系统笔设置闪退的问题，沿用宿主原生滑块与按压动画。
- 笔尖接触屏幕时退出激光、圈注或鼠标模式，并清除圈注笔迹。
- 独立管理器的“关于”页增加 GitHub 仓库入口，方便访问源码、版本和问题反馈。
- 暂时隐藏书写声音开关及音量设置，同时禁止声音引擎启用；旧配置及导入备份不会重新开启此功能。试听音源不包含在正式 APK 中。

版本号：`1.1`；versionCode：`51`；包名：`io.github.wondersready.focuspen`。沿用现有发布签名，可以覆盖升级并保留配置。本版仅包含 Xposed/LSPosed 模块，不包含 KernelSU 模块。

安装后请重启设备，让所有宿主加载新版。使用 ADB 安装时请使用 `adb install --no-incremental -r`，避免增量安装影响 LSPosed 冷启动加载。

澎湃 OS 3.x、4.x 沿用免小版本检查规则，仍需实际系统接口存在。主要开发设备为小米平板 8 Pro；其他机型不能视为已经验证。焦点笔 Pro 没有实笔验证，鼠标指南中笔的姿态仍待后续打磨。

发布前已完成配置迁移、备份恢复、输入、演示、鼠标、系统版本判断及更新检查的主机回归；滑条已完成设备拖动、松手保存与取消检查并获用户认可。主机测试不代替实笔验收，书写声音试听未通过，因此本版停用。
