# FocusPen 1.0.1 Beta

修复系统小版本升级后模块因版本锁定而停止加载的问题。

- 澎湃 OS 3.x、4.x 不再检查完整 ROM 指纹或系统组件的小版本号。
- 系统输入、激光运动、SystemUI 和系统笔设置使用统一的主版本判断；澎湃 OS 5.x 及之后版本等待适配。
- 保留实际类、方法和接口签名校验，系统接口缺失时记录错误。
- 沿用 1.0 Beta 功能、配置和签名，可直接覆盖升级。本版不包含正在开发的 1.1 书写音效或 KernelSU 音频模块。

版本号：`1.0.1-Beta`；versionCode：`47`；包名：`io.github.wondersready.focuspen`。

安装后重启设备以更新所有宿主。使用 ADB 时请使用 `adb install --no-incremental -r`，避免增量安装影响 LSPosed 冷启动加载。

放宽版本门槛不等于所有澎湃 3.x／4.x 机型均已验证。没有 Pro 实笔，Pro 硬件兼容性仍未验证。
