# FocusPen 1.0 Beta

版本：`1.0-Beta` · versionCode：`46` · 标签：`46-1.0-Beta`。

## 本次更新

- 统一接管标准版三键及 Pro 逻辑输入；单击、双击、长按、组合与模式切换由同一控制器判定。
- 激光松键跟随、圈注清除、系统原生鼠标、左右键与拖动；切换应用或打开控制面板保持鼠标模式。
- 锁屏与解锁前后继续接管；鼠标模式侧键为左右键，退出后恢复锁屏速记和截图入口。
- 磁吸归位关闭激光、清空圈注、退出鼠标并屏蔽按键；取下后恢复。
- 圈注指示笔尾显示当前颜色，旧笔迹保留原色。
- 长按和双击合并为快速／标准／柔和三档滑动条，带档位刻度。
- 弧形菜单选择和排序修复；应用列表异步缓存；应用配置图标与只负责勾选的添加页面。
- 原装手写动画与指南预加载、息屏速记点击波纹演示。
- 真正的 MIUIX 独立管理器、平板布局、配置备份；每日自动检查 GitHub 更新及手动检查入口。

## 安装与迁移

包名现为 `io.github.wondersready.focuspen`。旧包 `com.focuspen.enhance.v2` 与其属于不同应用：先在旧版导出配置，再安装新版并导入，在 LSPosed 中停用旧模块、启用新模块，最后重启。请勿同时启用两包。

静态作用域：`system`、`com.android.systemui`、`com.miui.securitycore`、`com.xiaomi.touchservice`。本版为非调试 Release，使用专用发布签名；已验证从新包名的 rc1 测试签名保留数据升级。

## 已验证与已知限制

标准笔已分项实测：激光松键跟随，清除不误入鼠标，原生指针点击与控制面板拖动，锁屏进入鼠标后解锁与退出，磁吸归位清理，圈注笔尾切色与旧笔迹保色。新包已核对首次解锁前控制器加载与配置迁移。以上是对应场景的记录，不代表全部边界通过。

当前适配 Xiaomi Pad 8 Pro 的指定 ROM：`Xiaomi/piano/piano:17/CP2A.260605.016/OS4.0.2.0.XPYCNXM:user/release-keys`。其他 ROM 未验证。

- 没有 Pro 实笔，相关逻辑和模拟测试不构成硬件验收。
- 鼠标指南笔身姿态将在下一版完善。
- 按住鼠标键时归位、开机已归位、断连、重复／取消键事件及部分窗口变化仍待进一步实测。
- 自动更新只检查并提供发布页入口，不静默安装；网络故障与 GitHub 限流会显示检查未完成。
