# 设计与边界

## 系统输入

`PenKeyHost` 在已核对的 ROM 按键策略入口进行仲裁。`KeyArbiter` 管理短按、长按、双击及其互斥关系。`NativeKeyReplay` 保留原始按键身份及按下／抬起配对；排队动作绑定窗口、配置版本和输入会话，焦点改变后丢弃旧动作。

“交给前台应用”的目的，是保留第三方应用自己的笔操作，同时避免重新触发系统速记／截图快捷策略。与自定义长按或双击组合时可能需要等待仲裁，不承诺零延迟。

标准笔鼠标模式使用速记键作为左键、截图键作为右键，按住拖动；焦点键的短按、双击、长按由模块状态机独立仲裁，空闲双击进入或退出鼠标，圈注中双击清除笔迹。原生焦点键点击计时被消费，绘制仍调用系统控制器。Pro 的轻捏、连捏、笔身双击和滑动由独立输入适配器仲裁；默认应用动作直接转发原始按键对，默认轻捏根据系统场景定向打开面板或交给应用。两笔均遵守硬件、锁屏与游戏边界，不能用标准笔事件模拟结果代替 Pro 实测。

## 配置与界面

`ConfigStore`、`ConfigSnapshot` 和跨进程配置桥为各宿主提供一致配置。全局设置作为默认，应用配置可逐项覆盖或继承模板。应用归属取当前焦点窗口。

`SettingsHooks` 复用系统 Preference 与宿主素材，更新时尽量保留页面和行对象。独立 MIUIX 管理器只承担加载状态、配置备份、调试预览和关于页。宽窗使用侧栏，窄窗使用底部导航。

## 快捷环与教程

快捷环在弹出时确定位置及朝向，选择期间保持固定；边缘空间不足时避边。点击图标执行，点击浮层外取消。菜单支持两种灵感速记、区域截屏、小爱识屏及自定义应用。

教程以系统提供的平板、笔、按钮及动画资源为基础，按功能组织。自绘演示采用统一时间曲线，书写时正向出现笔迹、抬笔后回程，笔姿随路径变化。系统缺少对应 Pro 图片时显示素材缺失说明，不以标准笔素材冒充。

## 锁屏与息屏

锁屏菜单限定为两种速记与官方区域截屏。息屏速记独立开启并选择目标，不要求全局按键绑定速记。两种速记采用各自官方锁屏入口；显示在锁屏上方不等于解除系统认证。需要解锁的其他页面仍由系统处理。

## 验收原则

源码接入、本地替身测试、设备界面验证和真实硬件验证分别记录。0.7.6 的已知验收缺口见发布说明，后续开发不得将“构建成功”当作完整兼容验证。
