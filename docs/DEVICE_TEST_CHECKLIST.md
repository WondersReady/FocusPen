# FocusPen 设备验收清单

这份清单用于平板返回后的一次集中验收。每项都记录为“通过／失败／未测”，并注明实际加载的 APK、宿主进程和日志时间；替身测试通过不能代替实机结果。

## 0. 测试前准备

1. 记录安装包版本、versionCode、SHA-256，以及 LSPosed 中的实际加载版本。
2. 保留当前用户配置备份；测试新增模板、应用配置和菜单项目使用临时名称，结束后删除并恢复备份。
3. 先确认屏幕超时、静音模式、音量、自动旋转和深浅色主题；不要开启常亮作为测试前提。
4. UI 变化只重载 SecurityCore／设置宿主；涉及 `system_server`、SystemUI、TouchService 或输入 Hook 的版本才安排重启。
5. 记录 `logcat` 中的 `FocusPen`、`FocusPenKeys`、`FocusPenMouse`、`FocusPenLaser`、`WindowDirection` 和崩溃堆栈。

## 1. 设置页与教程

| 项目 | 操作 | 预期 |
| --- | --- | --- |
| 教程第 1–3 页 | 进入“认识触控笔”，横竖屏各翻完三页 | 平板、笔和按钮高亮风格一致；第二、第三页焦点键尺寸与第一页一致；描述为两行且不出现具体毫秒 |
| 手写输入 6 页 | 进入手写输入，逐页翻到第三页并暂停、继续、退出、重新进入 | 第三页不崩溃；图片层正常绘制；暂停后从原进度继续；离开页面不再回调旧动画 |
| 深浅色／动画 | 切换主题和系统动画开关后重进页面 | 文本、卡片、按钮和图片对比度正确；关闭动画时直接显示最终状态 |
| 自适应页面 | 打开内容不足一屏的设置页，上下滑动 | 无多余空白翻页；内容不足时不出现无意义滚动 |
| 进度与滑条 | 检查长按、双击、书写声音设置 | 轨道、圆点、数值和标题不重叠；触摸后立即更新，不需再次滑动页面 |

## 2. 全局按键与应用配置

| 项目 | 操作 | 预期 |
| --- | --- | --- |
| 短按默认 | 速记键、截图键分别短按 | 默认“不执行操作”时事件交给前台应用；不触发原生速记／截图 |
| 前台应用透传 | 在支持笔按键的应用中测试按下、重复、抬起；中途切换窗口和配置 | 应用收到同一设备、键码、扫描码、修饰键和配对的 DOWN／UP；配置变化时收到取消释放，不向新窗口泄漏 |
| 应用配置 | 为一个测试应用创建配置，覆盖长按、双击、短按和笔尖预览；切换到另一个应用 | 自动套用目标窗口配置；离开窗口恢复全局默认；窗口切换时取消旧延迟动作 |
| 模板 | 创建、编辑、套用、脱离、删除模板 | 已选项目置顶；候选按字母排序并显示统一大小图标；模板删除后应用恢复原自定义值 |
| 菜单拖动 | 在已选列表中直接拖动行本身，交换首项、末项和中间项；快速连续拖动 | 目标行实时让位；首尾可直接交换；松手位置立即保存；无闪烁、无需滚动后才刷新 |

## 3. 弧形菜单与悬浮预览

| 项目 | 操作 | 预期 |
| --- | --- | --- |
| 内容 | 验证默认两个速记动作和区域截屏；再添加应用和官方动作 | 图标按固定圆环位置展示；数量增加时弧度延长，满数量形成环；点击任意图标立即执行 |
| 取消 | 点击浮窗外、按键取消、切换窗口或锁屏 | 菜单关闭且不执行动作；旧回调不会重新打开或触发动作 |
| 材质 | 浅色／深色、模糊开启／关闭、横竖屏、分屏和小窗 | 复用系统侧栏材质分支；边缘有外侧高光，环内不泛光；系统降级时仍可用 |
| 笔尖预览 | 悬浮移动、落笔、抬笔、快速改变方向和靠近四边 | 淡蓝外向泛光圆环跟手；落笔消失；菜单与预览不随笔位置或方向漂移 |
| 菜单方向 | 在中部和四角以不同笔尖朝向开环 | 菜单布局固定；碰边时采用不越界的左／右默认布局；不出现裁切或命中区缩小 |

## 4. 标准版鼠标与演示换色

| 项目 | 操作 | 预期 |
| --- | --- | --- |
| 进入／退出 | 激光／圈注／保留笔迹均关闭时，焦点键快速双击；再次双击退出 | 进入鼠标模式；不会启动激光或圈注；再次双击结束会话 |
| 左右键 | 鼠标模式下短按速记键、截图键；按住移动后松开 | 速记键为左键、截图键为右键；按住期间可拖动；释放成对，不产生普通快捷动作 |
| 状态栏连续性 | 鼠标光标从应用内容移到状态栏、通知区域和返回应用 | 不退出鼠标模式，光标继续显示；只有明确退出、窗口失效或设备断连才结束 |
| 演示换色 | 激光显示时短按两侧键；圈注绘制中换色并继续书写 | 每次按键只切一档；不触发速记／截图；旧笔迹保留原色；新笔迹使用新色；激光不被原生回调隐藏 |
| 异常恢复 | 切换应用、锁屏、关闭增强、断开设备 | 清理按下状态和延迟任务；不留下虚拟鼠标键、常亮或激光会话 |

## 5. 锁屏与息屏

| 项目 | 操作 | 预期 |
| --- | --- | --- |
| 锁屏圆环 | 亮屏锁屏后呼出快捷环 | 仅显示笔记、小米创作、区域截屏三个固定入口；不读取应用菜单覆盖 |
| 锁屏速记 | 分别点击笔记和小米创作 | 走官方 `keyguard` 路由；按系统能力直接显示编辑页或按要求解锁；不误启动前台应用配置 |
| 锁屏截图 | 锁屏下使用截图键默认动作 | 固定走官方区域截屏；不被普通配置覆盖 |
| 息屏速记 | 息屏落笔，分别选择笔记／小米创作 | 独立开关生效，不要求全局按键绑定；只唤醒一次，不新增常亮锁 |
| 重启后首次解锁 | 重启后保持锁屏，测试一次息屏和锁屏动作，再解锁 | 配置可读；首次宿主初始化不丢失；解锁切换释放旧按键和待执行动作 |

## 6. Pro 预览与验证边界

- 在设置调试入口切换“标准版／Pro”只检查界面、教程、配置字段和菜单布局，不伪造 `InputDevice`，不把预览当作硬件通过。
- Pro 没有实笔，保留未验证项：笔身上滑／下滑换色、Pro 双击／滑动组合、Pro 鼠标及真实触控膜状态。
